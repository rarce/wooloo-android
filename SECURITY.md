# Security reports

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/rarce/wooloo-android/security/advisories/new)
(the repository's **Security** tab → **Report a vulnerability**). Only the maintainers can see the report.
Include the app version and how you installed it, and the steps to reproduce. There is no guaranteed response
time; this is a project maintained in spare time.

Use [GitHub Issues](https://github.com/rarce/wooloo-android/issues) for everything else, with sanitized
information: do not include passwords, tokens, private keys, terminal content, personal hostnames or exploit
instructions in a public issue.

wooloo mobile is distributed through Google Play (`dev.wooloo.mobile`, currently a closed test, see
[wooloo.dev/mobile](https://wooloo.dev/mobile/)) and as APKs on GitHub Releases. Only install it from those
channels. A production signer and support window for the GitHub APKs have not yet been declared. See
[release readiness](todo.md).
