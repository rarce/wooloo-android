# Security reports

Use [GitHub Issues](https://github.com/rarce/herdroid/issues) for sanitized reports.
Do not include passwords, tokens, private keys, terminal content, personal hostnames
or exploit instructions in a public issue. For a sensitive vulnerability, open only
a minimal request for a private reporting channel, without disclosing the vulnerability.
There is currently no advertised private contact or guaranteed response time.
Configuring and testing a private reporting channel remains a release prerequisite.

Updates ship through GitHub Releases. Only install artifacts from the project channel
and verify the published signer fingerprint. A production signer and support window
have not yet been declared. See [release readiness](todo.md).
